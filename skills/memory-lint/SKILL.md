# Memory Lint

**Type:** Engineer (light)
**Requires:** MemPalace MCP server

Health check for the palace, modeled on the llm-wiki "lint" pass: the bookkeeping humans abandon, done on demand. **Report-only toward MemPalace** — this skill must never call `mempalace_add_drawer`, `mempalace_update_drawer`, `mempalace_delete_drawer`, or `mempalace_kg_invalidate`. Merging wings, purging records, renaming rooms are the user's explicit decisions, made from this report.

The only writes are two files in `~/.claude/` (dotfiles-synced):

- `~/.claude/memory-lint.md` — the run log, newest first
- `~/.claude/references/mempalace-wings.md` — the generated wing index (replaces the hand-maintained list deleted from the global CLAUDE.md in v5.0.0; `qsave` and `mempalace-record.md` reconcile against it)

## Steps

### Step 1: Snapshot

Call `mempalace_status`. Record total drawers, the wing→count map, the room→count map. Read the previous `~/.claude/references/mempalace-wings.md` and the newest section of `~/.claude/memory-lint.md` if they exist (baseline for drift; absent on first run — say so in the report).

### Step 2: Five checks — all read-only

1. **Wing drift vs index.** Wings present in the palace but missing from the stored index (new since last run), and index entries whose wing vanished. First run: report all wings as unindexed.
2. **Split-brain clusters.** Normalise each wing name: strip a leading `python-` / `swift-` / `flutter-` prefix. Group by (a) exact match after stripping, (b) substring containment (`artur` ⊂ `artur-ep` ⊂ `python-artur-ep`). Report every cluster of ≥2 wings with per-wing drawer counts. Deliberately loose — a false positive costs one line of reading; a missed cluster costs another split-brain repair.
3. **Undocumented rooms.** Compare palace rooms against the room table in `<plugin>/skills/_shared/references/mempalace-record.md`. Report any room not in the table, with its count. Flag likely typos (edit distance 1-2 from a documented room, e.g. `decisions` vs `decision`).
4. **Stale paths (sampled).** Pick the 5 largest wings; for each, `mempalace_search` (query: the wing's dominant topic or "architecture decision files", limit 5). Extract every absolute path (`/Volumes/`, `/Users/`, `/home/`) from the results; check each with one `test -e` batch via Bash. Report `<stale>/<checked> paths stale (sample: N records across M wings)` — **always print the sample size; silent sampling reads as full coverage.**
5. **Index freshness.** Stored totals (drawers, wing count) vs live Step 1 numbers. Report the delta.

### Step 3: Regenerate the wing index

Overwrite `~/.claude/references/mempalace-wings.md`:

```markdown
# MemPalace Wing Index (generated — do not hand-edit)

> Generated by /vladyslav:memory-lint on YYYY-MM-DD. Total: <N> drawers, <M> wings.
> Consumers: qsave Step 1, _shared/references/mempalace-record.md (wing reconciliation).

| Wing | Drawers | What it holds |
|---|---|---|
| swift-calories | 9493 | <one line> |
...
```

Descriptions carry forward from the previous index; new wings get `unknown — verify`. Never invent a description for a wing you know nothing about.

### Step 4: Prepend the report

Prepend a dated section to `~/.claude/memory-lint.md` (create the file on first run; never edit older sections):

```markdown
## 2026-08-01

- Totals: <N> drawers / <M> wings (Δ since last run: +X drawers, +Y wings | first run)
- Check 1 — wing drift: <new wings list | none>
- Check 2 — split-brain: <K clusters: name (counts), ... | none>
- Check 3 — rooms: <undocumented: name (count)..., typo-suspects | none>
- Check 4 — stale paths: <S>/<C> stale (sample: N records, M wings) — <list stale paths>
- Check 5 — index freshness: <regenerated; was N days old | first generation>
```

### Step 5: One-screen summary

Render the same findings to the user, ordered by severity (split-brain and typo rooms first). End with:

```
Next: рішення по злиттю wing-ів / чистці кімнат — за тобою; memory-lint нічого не змінює в палаці.
```

## Failure modes

- **MemPalace unreachable** → one-line warning, stop. Never block, never guess.
- **`~/.claude/references/` missing** → create it (`mkdir -p`), note in the report.
- A check erroring must not abort the rest — run all five, report per-check errors inline.
